# AI Trend Lab

AI Trend Lab is a learning and content-generation platform for understanding current AI developments, trying practical workflows, and turning approved topics into shareable content.

## Current MVP slice

- Searchable AI trend library with category filters
- Learner progress and saved topics interactions
- Explore, Learn, and Create workspace navigation
- Content generator preview for website, LinkedIn, X threads, and Instagram carousel copy
- Human-review-oriented source and AI-assisted draft indicators
- Responsive visual system for desktop and mobile

## Run locally

```bash
npm install
npm run dev
```

Build for production with:

```bash
npm run build
```
